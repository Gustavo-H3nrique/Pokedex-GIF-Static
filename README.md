# 🎮 Pokedex-GIF-Estático

Uma Pokédex interativa desenvolvida com JavaScript, que permite visualizar Pokémon em versões estáticas e GIFs animados, consumindo dados da **PokeAPI**.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com o "trio parada dura" do Front-end:

* **HTML5**: Estruturação dos elementos da Pokédex.
* **CSS3**: Estilização, núcleos e layout responsivo.
* **JavaScript (ES6+)**: Lógica de consumo da API, manipulação do DOM e alternância de estados (GIF/Static).
* **PokeAPI**: Fonte de dados para os nomes, tipos e imagens dos Pokémon.

## 📋 Funcionalidades

- [x] Exposição dinâmica de Pokémon.
- [x] Alternância entre imagem estática e GIF animado.
- [x] Sistema de busca por nome ou ID.
- [x] Botões de navegação (Próximo e Anterior).
- [x] Design responsivo para dispositivos móveis.
